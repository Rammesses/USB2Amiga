# USB2Amiga — Coding Standards

## Language and Standard
- C11 (`-std=c11`). No C++.
- Target: RP2040 (Cortex-M0+). No dynamic allocation (`malloc`/`free`) in firmware paths.

## Formatting
Enforced by `.clang-format` (run `clang-format -i src/*.c src/*.h`):
- 4-space indent, no tabs.
- K&R brace style (opening brace on same line).
- 100-column limit.
- LF line endings (`.editorconfig`).

## Naming
| Thing | Convention | Example |
|---|---|---|
| Functions | `snake_case` | `ami_kbd_out_task()` |
| Types/structs | `snake_case_t` | `kbd_event_t` |
| Constants/macros | `UPPER_SNAKE` | `PIN_KCLK` |
| File-scope statics | `snake_case` | `static uint8_t phase_h` |
| GPIO pin macros | `GPIO_` prefix | `GPIO_H_A` |

## File Structure
Each module is a `.c`/`.h` pair. Headers use `#ifndef _FOO_H_` guards.
Source files include their own header first, then SDK headers, then project headers.

## Error Handling
- Functions that can fail return `bool` (true = success).
- Queue push/pop are non-blocking; callers must handle `false` return.
- No `assert()` in interrupt/PIO paths.

## Inter-Core Safety
- All cross-core data passes through the ring buffers in `event_queue.h`.
- Use `__dmb()` (from `hardware/sync.h`) around ring buffer head/tail updates.
- No shared mutable globals outside the queues.

## GPIO
- All Amiga-facing outputs are active-low unless noted.
- Open-drain lines (KCLK, KDAT): drive low via `gpio_set_dir(GPIO_OUT)` + `gpio_put(0)`, release via `gpio_set_dir(GPIO_IN)`.

## PIO
- PIO programs live in `src/*.pio`. Headers are generated by `pico_generate_pio_header()`.
- Each PIO program has a comment block explaining the TX FIFO word format.

## Commit Messages
`Phase N: short description` for phase work. Plain imperative for fixes.

## Pre-commit Checks
The `.git/hooks/pre-commit` hook runs automatically:
1. `clang-format` — format check on staged files
2. `cppcheck` — static analysis
3. `build.sh` — full compile

Fix format issues with: `clang-format -i src/*.c src/*.h`
